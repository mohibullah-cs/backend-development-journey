# FastAPI Docker Project

A backend development project demonstrating how to containerize a FastAPI application using Docker and Docker Compose.

## Technologies Used

- Python 3.12
- FastAPI
- Uvicorn
- Docker
- Docker Compose

## Features

- REST API development
- Docker image creation
- Containerized backend application
- Docker Compose configuration
- Health check endpoint
- Interactive API documentation

## Getting Started

### Build and Run

```bash
docker compose up --build
```

### Access the Application

Main API:
http://localhost:8000

API Documentation:
http://localhost:8000/docs

Health Check:
http://localhost:8000/health

### Stop the Application

```bash
docker compose down
```

## Learning Objectives

- Understanding Docker images and containers
- Writing Dockerfiles
- Managing containers using Docker Compose
- Understanding port mapping
- Containerizing FastAPI applications
